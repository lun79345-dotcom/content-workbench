# 内容工作台 · Content Workbench

面向短视频账号运营的协作工作台：把选题、脚本审核、拍摄、剪辑、成片审核、发布、数据登记、奖金清算与周复盘串在同一条流程中。

这是实际内部应用的**公开展示版本**，由陆建达整理用于展示业务流程与产品实现。内部版本已部署并发布企业飞书应用；公开版本独立维护，不携带企业部署配置、员工资料、运营数据、凭据或内部 Git 历史。所有预置人物、账号、视频、指标及奖金规则均为虚构示例，不代表公司经营结果。

[个人官网项目介绍](https://nickstudio.cn/content-workbench.html) · [English README](README.en.md)

## 本地体验

需要 **Node.js 22.13+**（使用 `node:sqlite`）及 npm。无需飞书账号或付费接口。

```sh
git clone https://github.com/lun79345-dotcom/content-workbench.git
cd content-workbench
npm ci
npm run seed:demo
npm run dev
```

打开 <http://127.0.0.1:3000>，选择虚构的老板、编导或剪辑身份。开发服务默认只监听本机。`seed:demo` 只创建空数据库，遇到已有成员或业务数据会拒绝覆盖。跳过它时，应用会自动创建基础示例成员与账号，不添加视频。

建议先用老板身份看驾驶舱和生产看板，再切换到编导或剪辑查看任务、审核、数据及奖金；使用指南按岗位说明各流程。登录页的身份切换是本地演示功能，并非真实身份认证。

## 产品流程

- **生产与审核**：八阶段看板、责任人和截止日、脚本与成片审核、打回原因、需求变更和阶段记录。
- **数据与复盘**：发布后第 7／30 天登记、账号月度目标、指标汇总和个人周复盘。
- **奖金**：按可配置的示例档位计算、30 天升档补差、按人汇总、公示后锁定、CSV 导出。
- **创意与投稿**：创意评级与排期、学生投稿授权确认、入围或采用后进入创意库。
- **飞书能力**：OAuth 登录、待审批角色、机器人消息卡片；需自行配置企业应用与可用范围。
- **提醒**：截止前／当天／逾期、审核及数据补录提醒；支持关闭后台任务。

**指标边界**：抖音和视频号播放量由人工登记。TikHub 接入仅用于代码支持的互动数据辅助同步；没有凭据时不调用。公开演示数据并非来自真实平台采样，奖金金额和分成也不是公司实际制度。页面中的示例时限可按自己的制度调整。

## 可选配置

参考 `.env.example`，将需要的字段写入自己的 `.env.local`。不配置飞书和 TikHub 也能本地体验。演示登录、默认示例成员只适合本机测试；对外部署前须关闭演示登录、使用独立数据库和随机会话密钥，停用示例身份并配置自己的飞书应用。

公开版本通过经核对的 `BOSS_FEISHU_OPEN_IDS` 引导管理员，其他新用户进入待审批；**不会按显示姓名绑定示例成员或授予管理员权限**。集成代码保留用于阅读和自行配置，公开版未连接企业租户执行真实登录、消息送达或第三方数据测试。

```sh
npm run lint
npm test
npm run build
```

`npm test` 覆盖双平台数据齐备、奖金补差、重复计算和公示锁定等业务规则。构建后的生产模式需要 `SESSION_SECRET`；默认关闭演示登录。当前实现采用 SQLite，适用于单实例体验，未验证多租户隔离与分布式部署。

## 目录与实现

`src/app` 为 Next.js App Router 页面与服务动作；`src/lib` 包含流程规则、SQLite、飞书、通知及数据同步；`scripts/seed-demo.mjs` 生成虚构示例；`tests` 验证奖金业务规则。主要技术为 Next.js 15、React 19、TypeScript、Tailwind CSS 4 和 SQLite。
